# Nexora branding

## Brand name

**Nexora** is the customer-facing name for this product. It communicates a connected, forward-looking messaging workspace without tying the SaaS product to the upstream inspiration project.

## Positioning

> Open messaging infrastructure for teams that want control, clarity, and a better developer experience.

## Voice

- Clear and technical, without sounding cold.
- Confident, but do not promise guaranteed delivery or account safety.
- Prefer “workspace”, “connection”, “delivery”, and “workflow”.
- Explain operational behavior in plain language.
- Always make consent, privacy, and self-hosting boundaries clear.

## Visual direction

- Deep forest green for the product shell and hero surfaces.
- Lime green for action, success, and active connection states.
- Warm off-white backgrounds for public content sections.
- Monospace terminal panels for developer credibility.
- Soft borders, restrained shadows, and rounded cards for the SaaS workspace.

## Usage rules

- Use **Nexora** in product copy, metadata, screenshots, and documentation.
- Use the repository slug `WhatsApp_saas` only where a GitHub URL or local folder is required.
- Do not present Nexora as affiliated with Meta or WhatsApp.
- Keep API route names stable for compatibility; branding does not require changing `/api` endpoints.
